# Data Analysis & Quantitative Reasoning

## Workflow
1. Identify the question, unit of analysis, time range, and decision the analysis should support.
2. Inspect schema, data types, missing values, duplicates, outliers, and data provenance.
3. Clean data transparently; preserve raw data.
4. Use reproducible calculations and state assumptions.
5. Choose appropriate statistics and visualizations.
6. Check totals, denominators, edge cases, and sensitivity.
7. Explain results in plain language with limitations.

## Rules
- Never fabricate missing observations.
- Distinguish correlation from causation.
- Show units, time windows, and sample sizes.
- Avoid misleading axes or chart types.
- Make calculations reproducible and verify key figures independently.
