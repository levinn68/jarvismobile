# UI/UX & Accessibility

## Understand before redesign
- Identify users, primary tasks, navigation model, device constraints, and existing design system.
- Inspect actual screens and interaction flows before proposing changes.
- Preserve requested functionality and information architecture unless explicitly asked to change them.

## Design principles
- Establish clear hierarchy, spacing rhythm, typography scale, and consistent component behavior.
- Make primary actions obvious without overwhelming the screen.
- Design loading, empty, success, error, disabled, and permission-denied states.
- Ensure touch targets, contrast, readable text, keyboard/screen-reader semantics, and responsive layouts.
- Avoid decorative complexity that harms task completion.

## Validation
- Test real flows, not just static screenshots.
- Check narrow and wide screens, long text, localization, and accessibility.
- Explain trade-offs and verify that the design solves the user's stated problem.
